# 기질냥구소 (gijilnyang)

아이 기질 · 부모 성향 · 둘의 궁합을 공개 연구와 검증된 척도 기반으로 정리해 주는 리포트 앱.

> **테스트 단계입니다.** 검색엔진에는 노출되지 않도록 `noindex` 를 걸어두었습니다.
> 정식 오픈 시 `<meta name="robots">` 줄을 제거하세요.

- 배포물: `index.html` 한 파일 (의존성 0)
- 소스와 빌드 스크립트는 별도 관리 (`성향기질앱/src`, `tools/build.ps1`)
- 전문 심리검사·진단·상담이 아니라, 공개된 연구와 검증된 척도를 학습한 정보 기반 리포트입니다.
